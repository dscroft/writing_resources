When writing your dissertation you should use the past tense as much as possible.
This is because you are writing about work that has already been done, not work that you are currently doing.

If you are writing about work that is ongoing, such as a project that is still being developed, then you can use the present tense as appropriate.

If you are writing about work that you will do in the future, such as a proposal for a project that you have not yet started, then you can use the future tense as appropriate.
