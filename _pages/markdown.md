I personally do not use Word or similar software for my own writing.

I use [Markdown](https://en.wikipedia.org/wiki/Markdown) to write my documents and then convert them to PDF, LaTeX, Word or HTML as needed.
This website for example is written in Markdown.

There are a number of advantages to using Markdown, including file management, version control, don't need to worry about formatting.
However, it does require a learning curve. 

I am happy to discuss this with you if you are interested in using Markdown for your dissertation.
